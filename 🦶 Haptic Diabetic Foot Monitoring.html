Wearable Diabetic Foot Monitoring System

Embedded Sensor Integration & Kinematic Gait Analysis

01 \ Problem Statement

Diabetic foot ulcers are a severe clinical complication, frequently resulting in infection and lower-limb amputations. Due to peripheral neuropathy, patients lose sensation and cannot detect the repetitive pressure and abnormal gait changes that cause tissue breakdown.

Because standard clinical checks only offer intermittent assessments, this project aimed to develop an in-shoe wearable system to monitor walking mechanics continuously and catch early risk profiles.

02 \ The Experiment

Built an integrated in-sole hardware system evaluated through sequential, synchronized user walking paths:

  • Sensing Matrix: Mapped Force Sensitive Resistors (FSRs) at primary plantar loading zones alongside an MPU6050 IMU on the foot to record dynamic force and 3-axis motion profiles simultaneously.
  • Hardware Hub: Used a Raspberry Pi Pico 2 to aggregate real-time sensor streams over custom low-latency Python acquisition scripts.
  • Data Rigor: Performed successive walking trials to verify time-synchronization across modalities and reduce recording variance.

03 \ Results

The system accurately aligned and processed multi-modal sensor telemetry to map distinct stride features:

  • Kinetic Capture: Force array data explicitly mapped dynamic plantar pressure transfer throughout the stance phases.
  • Kinematic Tracking: IMU spatial measurements isolated clear acceleration and angular velocity signatures for swing-to-strike transitions.
  • Sensor Fusion: Merging pressure data with inertial movement arrays captured a complete representation of gait stability that single-sensor architectures miss.

04 \ Discussion

The project proves that combining in-shoe pressure maps with spatial motion tracking creates a powerful framework for continuous biomechanical screening. While clinical patient trials are the next step, the prototype delivers a high-fidelity foundation for passive ulcer-prevention tools.

Developing this platform advanced core competencies across hardware-software integration, real-time data streaming, signal processing loops, and experimental hardware testing.
